# Museum accession records and object storage

## Collection cataloguing

Assign an accession number before moving a newly accepted object. Record the donor, maker, material, dimensions, and any known provenance. Photograph distinguishing marks and attach the conservation assessment. Link components belonging to one object while retaining a separate record for each physical piece.

## Museum storage

Place fragile objects in fitted trays with inert padding. Keep organic materials away from damp exterior walls. Log shelf positions so an object can be located without opening every container. Inspect humidity readings each morning and document changes in surface condition before an object is moved.
