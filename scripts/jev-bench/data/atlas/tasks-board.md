# Retired Tasks feature

The current canvas task list and board use the new `/todos` API and `*_todo` MCP tools. See [Canvas tasks](../todos.md) for the current product contract. The retirement below describes the previous standalone Tasks feature.

The standalone Tasks board and its HTTP, chat, and MCP tools were removed on 2026-10-06. Existing local task records were deleted at the user's request. Documents and Markdown checklists remain available.

This page is retained so links from historical design and implementation notes still resolve. Those notes describe an earlier version and are not the current product contract. See the root README and API reference for current features.
